# Oportunidades de autoridad externa

Se revisó el inventario suministrado: **616 dominios únicos**. La clasificación completa está en `offpage-domain-classification.csv`. Es un triaje basado en la exportación, no una validación web de todos los dominios. Las categorías y scores no garantizan calidad ni acceso.

## Categorías

| Categoría | Criterio de selección |
|---|---|
| universidad | Vínculo académico o colaboración documentada |
| revista científica | Autoría, DOI y afiliación comprobados |
| organismo público | Referencia pública pertinente al trabajo |
| asociación | Actividad o colaboración real |
| repositorio | Obra legítima y permisos de depósito |
| medio especializado | Cobertura editorial relevante |
| directorio legítimo | Entidad editorial e identidad verificadas |
| partner | Relación comercial o científica confirmada; ninguno se presume |
| institución | Naturaleza por verificar cuando falten datos |
| artículo técnico | Página concreta que pueda citar una fuente útil; no se deduce del dominio |
| basura/PBN | Anclas explícitas de venta de enlaces o PBN; exclusión preventiva |

## Prioridad científica y acciones

1. Verificar perfiles y producción científica de los especialistas.
2. Identificar relaciones institucionales reales antes de proponer una mención.
3. Considerar artículos técnicos útiles como recursos citables, sin solicitar intercambios artificiales.
4. Documentar URL, contexto, contacto público y motivo de pertinencia antes de cualquier decisión del cliente.

No se enviaron mensajes, no se compraron enlaces y no se modificaron cuentas. No se generó disavow: las señales de dominios de competidores no prueban riesgo para el dominio propio.
