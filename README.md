# 🌿 Caminando Otro Sendero - Sitio Web

Sitio web profesional de **Caminando Otro Sendero**, empresa especializada en consultoría ambiental, investigación y educación ambiental. Razón social vigente confirmada por su titular: **Caminando Otro Sendero SpA**, RUT **76.932.987-0**.

## 📋 Descripción

Este es un sitio web completamente responsivo construido con HTML5, CSS3 y JavaScript vanilla. Incluye todas las secciones necesarias para una empresa de consultoría ambiental de alta calidad.

## ✨ Características

### Secciones Principales
- ✅ **Hero/Header** - Carrusel automático de imágenes
- ✅ **Servicios** - 4 servicios principales con animaciones
- ✅ **Nosotros** - Información de la empresa
- ✅ **Investigaciones** - Publicaciones científicas con enlaces
- ✅ **Experiencias** - Timeline interactivo de proyectos
- ✅ **Galería de Proyectos** - Showcase de trabajos realizados
- ✅ **Estadísticas** - Números animados del impacto
- ✅ **Equipo** - Tarjetas de profesionales
- ✅ **Testimonios** - Reseñas de clientes
- ✅ **Galería de Especies** - Catálogo de fauna estudiada
- ✅ **FAQ** - Preguntas frecuentes interactivas
- ✅ **Cotización** - Formulario para solicitar presupuestos
- ✅ **Contacto** - Información de contacto y formulario

### Funcionalidades
🎨 **Diseño Responsivo** - Se adapta a cualquier dispositivo
🎬 **Carrusel Automático** - En el header con indicadores
⚡ **Animaciones Suaves** - Transiciones elegantes al scroll
📱 **Menú Hamburguesa** - Navegación móvil
🔍 **Iconos y Emojis** - Diseño visual atractivo
💫 **Efectos Interactivos** - Hover effects, botones animados
🎯 **Números Animados** - Contador automático en estadísticas
❓ **FAQ Dinámico** - Expandible al hacer click

## 🚀 Cómo Usar

### Instalación Local
```bash
# Clonar el repositorio
git clone https://github.com/DiegoSalsa/CaminandoOtroSendero.git

# Navegar a la carpeta
cd CaminandoOtroSendero

# Iniciar servidor local (Python 3)
python -m http.server 8000

# Abrir en navegador
# http://localhost:8000
```

### Agregar Imágenes
1. Coloca imágenes en la carpeta `images/`
2. Actualiza las rutas en `index.html` si cambias los nombres
3. Formatos soportados: JPG, PNG, WebP

### Personalizar Contenido
- **index.html** - Estructura y contenido
- **styles.css** - Estilos y diseño
- **script.js** - Funcionalidades interactivas

## 🎨 Personalización de Colores

Los colores principales están definidos en `styles.css`:

```css
:root {
    --primary-color: #27ae60;        /* Verde */
    --secondary-color: #3498db;      /* Azul */
    --accent-color: #f39c12;         /* Naranja */
    --text-dark: #2c3e50;            /* Gris oscuro */
    --text-light: #34495e;           /* Gris claro */
    --bg-light: #ecf0f1;             /* Fondo claro */
}
```
